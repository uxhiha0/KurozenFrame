# Kurozen Frame

A lightweight HOME launcher/dashboard built specifically for the T-1 / W08 Allwinner A33 digital photo frame running Android 4.4.2.

## v0.1
- Android HOME launcher
- Android 4.4 / API 19 compatible
- Black/crimson Kurozen + DZG dashboard
- Live clock/date
- Launches the original V Photo app
- Android Settings shortcut
- Does not replace or modify CloudPhotoFrame.apk

## Device
- Model: T-1
- Device: W08
- SoC family: Allwinner sun8i / A33
- Android: 4.4.2
- Stock frame package: com.waophoto.smartframe
- Stock activity: com.waophoto.smartframe.ui.SplashActivity

## Safety
Test Kurozen Frame as HOME using "Just once" before setting it as the permanent default. The stock V Photo application remains installed.
